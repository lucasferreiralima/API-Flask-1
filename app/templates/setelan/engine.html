Arquitetura do Motor de Dados (ETL)

1. Extração (Extract)

O sistema utiliza a biblioteca Pandas para realizar a leitura de múltiplas abas de arquivos Excel. O motor é capaz de processar arquivos .xlsx, .xls e .xlsm de forma agnóstica a nomes de colunas, utilizando um mapeamento de alias (ex: "Faturamento" ou "Valor Líquido" são normalizados para o mesmo campo).

2. Tratamento (Transform)

Durante o processamento, aplicamos regras de Data Cleaning:

  • Conversão de tipos (Decimal para Float para precisão matemática).
  • Normalização de strings (Remoção de espaços e acentos em status).
  • Tratamento de valores nulos (Fillna) para evitar quebras em cálculos de margem.
  • Cálculo dinâmico de indicadores (Ticket Médio e Atingimento de Meta).

3. Carga (Load)

Os dados tratados são persistidos em um banco PostgreSQL (ou SQLite em ambiente dev) através do SQLAlchemy. O processo garante integridade referencial, ligando automaticamente vendas aos seus respectivos vendedores, lojas e produtos através de chaves estrangeiras.

Stack Tecnológica da Solução:

Python 3.11 Pandas (Dataframes) OpenPyXL (Excel Engine) SQLAlchemy (ORM) Gunicorn (WSGI) Docker (Containerization)

Confiabilidade

Automação que elimina o erro humano comum em consolidações manuais de Excel.

Escalabilidade

O motor está preparado para processar arquivos com dezenas de milhares de linhas sem perda de performance.

Visibilidade

Transformação instantânea de dados "frios" de planilhas em KPIs acionáveis.
